# 💰 Smart Save – Personal Finance Tracking App

Smart Save is an Android-based personal finance tracking application designed to help users manage their income, expenses, and savings efficiently. The app provides clear insights into spending habits, supports budget planning, and promotes better financial decision-making through simple and intuitive features.

---

## 📌 Project Overview

Managing personal finances can be challenging without proper tools. **Smart Save** helps users:
- Track daily transactions
- Categorize income and expenses
- Set monthly budgets
- Monitor spending trends
- Receive alerts when budgets are exceeded

The app is built with a focus on usability, performance, and data persistence.

---

## 🎯 Objectives

- Enable users to record and manage financial transactions
- Provide category-wise expense analysis
- Allow monthly budget setup and monitoring
- Store data securely on the device
- Improve financial awareness and savings habits

---

## ✨ Key Features

- 📥 **Transaction Management**
  - Add, edit, and delete income and expense records
  - Record amount, category, date, and description

- 🗂️ **Category-wise Analysis**
  - Organize transactions into categories
  - View spending patterns by category

- 📊 **Dashboard Overview**
  - Summary of total income, expenses, and balance
  - Monthly financial snapshot

- 💸 **Budget Management**
  - Set monthly budgets
  - Get alerts when budget limits are exceeded

- 🔔 **Notifications**
  - Budget alert notifications
  - Helpful reminders for financial control

- 💾 **Data Persistence**
  - Uses SharedPreferences and internal storage
  - Backup and restore functionality

---

## 🛠️ Technologies Used

- **Platform:** Android
- **Language:** Kotlin
- **UI:** XML Layouts
- **Architecture:** Fragment-based navigation
- **Storage:** SharedPreferences, Internal Storage
- **Tools:** Android Studio
